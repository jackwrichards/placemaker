# Placemaker

A Cities: Skylines II mod. Select an area, pick what goes there, preview it, hit Build.
Roads, parking, parks, beaches, shops, nature, farms, sports, industrial and zoning. Only the game's own assets.

Early access. Back up your save.

- Get it: [Paradox Mods](https://mods.paradoxplaza.com/mods/163638/Windows)
- Showcase: [YouTube](https://www.youtube.com/watch?v=Fa5TWC3B-Ps)
- Bugs: [Issues](https://github.com/jackwrichards/placemaker/issues) (a screenshot and your Placemaker.log help a ton)

Some code is ported from [Parking Lot Tool](https://github.com/KruemelGames/ParkingLotTool)
and [ParkManager](https://github.com/tomkpunkt/ParkManager). Uses [Harmony](https://github.com/pardeike/Harmony) (MIT).
