**Placemaker 0.3.0 is out!** 🎉

Hey all, a big one this time. Here's the good stuff:

📸 **Every style now has a photo**, so you can see what you're getting before you pick it. And no more "Standard": every style has a real name now (Playing fields, Town grid, Temple garden...).

🗺️ **The preview got a glow-up.** The sketch now looks like an actual site plan: roads, paths, lawn, parking spaces, trees, even the cars and benches. There's a little top-down map next to the panel too. Planned ponds show up as water before you build.

🌿 **Vanilla by default.** Placemaker only uses vanilla stuff on its own now, so no more surprise mod surfaces or decals. You can still pick any asset you like yourself.

💰 **Park upkeep fixed.** The upkeep you see before building is now what you actually pay. (Sorry to everyone whose ¢50 park turned into a ¢20k budget hole 😅) Heads up: a park only counts as a park when it's grouped as one asset. Review tells you if it isn't.

🛣️ **Roads don't zone anymore.** That's what the Zoning category is for.

🌳 **Outgrow (beta) is way faster and smoother.** Fewer weird fences, no gardens under bridges or over streets, and a much simpler window.

🌍 **Placemaker now speaks 12 languages!**

⚡ Plus it's a lot faster overall, and a bunch of smaller fixes.

Let me know what you build! ❤️
