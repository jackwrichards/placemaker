Placemaker 0.3.0 is up on Paradox Mods.

Main changes:
- Every style has a photo now, so you can see what it builds before picking it. "Standard" is gone, every style has its own name.
- The sketch preview is now a proper site plan: roads, paths, lawn, parking spaces, trees, cars, benches. There's also a small top-down map next to the panel. Planned ponds show as water before you build.
- Placemaker only picks vanilla assets on its own now. No more mod surfaces or decals showing up unasked. You can still choose any asset yourself.
- Park upkeep is fixed. The upkeep shown before you build is what you actually pay (it was leaving out the park's running cost). A park only counts as a park when it's grouped as one asset, and Review warns you if it isn't.
- Roads don't zone anymore, use the Zoning category for that.
- Outgrow (beta) is a lot faster, fences are cleaner, no more gardens under bridges or over streets, and the window is simpler.
- Translated into all 12 game languages.
- Faster planning overall, plus a bunch of smaller fixes.

Let me know if anything breaks.
